# Design System

This document outlines the visual foundation of the Anoir application, inspired by a light, premium, minimalist SaaS aesthetic.

## Overall Visual Formula
- **80%** White / Neutral backgrounds
- **15%** Dark text for contrast and readability
- **5%** Accent color (Indigo) to guide the user's eye and highlight interactions

---

## Colors

### Core Palette
- **Primary**: `#111827` (Deep Ink)
- **Secondary**: `#4F6EF7` (Refined Indigo)
- **Background**: `#F8FAFC` (Soft White)
- **Cards**: `#FFFFFF` (Pure White)
- **Text**: `#0F172A` (Slate 900)
- **Muted text**: `#64748B` (Slate 500)

### Feedback / Semantic
- **Success**: `#16A34A` (Green 600)
- **Warning**: `#D97706` (Amber 600)
- **Error**: `#DC2626` (Red 600)
- **Info**: `#2563EB` (Blue 600)

### Supporting & Interactive
- **Border**: `#E2E8F0`
- **Subtle background**: `#F1F5F9`
- **Primary hover**: `#0F172A`
- **Secondary hover**: `#4059D6`
- **Primary light**: `#EEF2FF`
- **Success light**: `#F0FDF4`
- **Warning light**: `#FFFBEB`
- **Error light**: `#FEF2F2`
- **Info light**: `#EFF6FF`

*Note: Do not overuse the indigo. Most of the interface should remain white, gray, and black. Indigo should exclusively tell the user where to look.*

---

## Typography

**Primary Font**: [Geist](https://vercel.com/font)

### Heading Sizes
- **Display**: 64px / 72px line-height
- **H1**: 48px / 56px line-height
- **H2**: 36px / 44px line-height
- **H3**: 28px / 36px line-height
- **H4**: 22px / 30px line-height
- **H5**: 18px / 26px line-height

### Body Sizes
- **Large**: 18px / 28px line-height
- **Default**: 16px / 24px line-height
- **Compact**: 14px / 20px line-height

### Small Text
- **Small**: 12px / 18px line-height
- **Labels / Metadata**: 13px / 18px line-height

### Font Weights & Typographic Rule
- **Regular (400)**: Normal content
- **Medium (500)**: Buttons / Navigation / Labels
- **Semibold (600)**: Section titles / Important UI elements
- **Bold (700)**: Major headlines

*Key Rule: Don't make everything bold. Use lighter weights for most content to maintain a quiet, expensive SaaS aesthetic rather than a loud, heavily-bolded dashboard.*
